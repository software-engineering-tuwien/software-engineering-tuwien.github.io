Team and Overview

In this master's-level project course you develop a larger software system in a team, working with the architectures, tools and automation practices that characterise advanced software systems. Your team proposes its own project, agrees on a project contract, implements it over the semester, and defends its progress in management reviews before presenting the result at the ASE Day.

Learning outcomes

After successfully completing this course, you are able to

  • estimate and quantify the properties of large software systems;
  • apply development procedures typical for large software systems;
  • implement and understand architectures of large software systems;
  • apply approaches to developing software for mobile devices;
  • evaluate and select tools and frameworks for specific problems;
  • understand and apply tools and frameworks for large software systems.
Contents
  • Characteristics of advanced software systems
    • System size and complexity
    • System dependability, Quality of Service (QoS)
    • Extended software lifecycle
    • Mission and safety criticality
  • Software engineering approaches for advanced software systems
    • Architecture styles, such as component-based software engineering
    • Lifecycle management and documentation
    • Software design patterns
  • Component-based engineering of complex software systems
  • Automation in developing advanced software systems
    • Source code management
    • Continuous integration and testing
    • Advanced build management
    • Persistence techniques (e.g. object-relational mapping)
  • Aspects of enterprise architectures
  • Selected research and industrial topics
    • Software engineering for mobile devices
    • Migration project case studies
    • Ecosystems for software engineering tools and frameworks
Methods
  • Carrying out a medium-sized software project in a team of 4–6 people
  • Intensive supervision of the teams by a tutor
  • Intensive use of corresponding software development tools and methods

Assignments

The course amounts to 150 hours of work (6 ECTS), distributed roughly as follows.

Getting started

  • Preliminary discussion — 1 hour
  • Preparation for the entry test — 1 hour
  • Entry test — 4 hours
  • Finding ideas, project proposal, project contract — 5 hours
  • Kickoff meeting — 1 hour

Project phase

  • 12× meeting with the tutor — 12 hours
  • 3× management review — 3 hours
  • Preparation for presentations (management reviews, ASE Day) — 3 hours
  • Group-internal meetings and project management — 30 hours
  • Familiarisation with the technologies — 10 hours
  • Implementation — 60 hours
  • Quality assurance and testing — 18 hours
  • ASE Day — 2 hours

Grading

The necessary qualifications are checked at the beginning of the course by means of an entry test, which must be passed positively.

Your performance is then assessed in the framework of several management reviews during the project phase.

The examination mode is continuous assessment (prüfungsimmanent).
